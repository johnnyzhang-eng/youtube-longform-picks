# 长视频精选台

用 YouTube 上的优质长视频，替代刷短视频。

方向是 AI 和心理学。每个视频都配了两句话：**为什么看**、**带着问题看**。看完点“复制小记模板”，链接和问题自动填好，粘贴到自己的笔记里写两三句就行。

## 打开

直接用浏览器打开 `index.html`。不需要安装任何东西；缩略图要联网才显示，没有 JavaScript 也能完整阅读。

页面上可以按主题、按时长筛选，也能标记“已看”（只记在当前浏览器里）。

## 结构

| 文件 | 作用 |
|---|---|
| `videos.json` | 全部内容：分组、每组说明、每个视频的标题、频道、时长、日期、推荐理由和问题 |
| `template.html` | 页面样式和交互 |
| `build.py` | 把 `videos.json` 填进 `template.html`，生成 `index.html` |
| `index.html` | 生成的页面，可以直接打开 |

## 更新

1. 在 `videos.json` 里加、删、改视频。新视频先在 YouTube 上确认能播放，再填时长和日期。
2. 运行 `python3 build.py`（只用 Python 标准库）。

## 选片说明

由 Opus 按作者口碑、课程或机构来源、标题和时长挑选，没有逐个看过。每个链接都在 `videos.json` 的 `updated` 日期核对过能播放。
