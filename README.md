# 长视频精选台

把刷短视频的时间，换成值得看的长视频。

在线打开：<https://johnnyzhang-eng.github.io/youtube-longform-picks/>

## 里面有什么

- **主线 6 步**：讲清大模型怎么工作。每一步一个问题，问题和参考要点都对照作者公开的讲义核对过。
- **候选池**：定期从白名单频道的新视频和内行社区的高分视频里筛出来的一批，自己挑着看，定期换新。筛选逻辑见选片标准。
- **资料库**（默认折叠）：认真学的分支（数学补给、AI 延伸、读一篇论文、AI 应用、计算机基础、数据库与数据工程等）和轻松看（访谈、心理学、思维模型）。
- 学习闭环：看完先用自己的话回答，再对照参考要点；写下回答 3 天后，页面提醒不看笔记再讲一次。
- 参考要点分两种：对照过来源的会标明来源；没核对过的标“未核对”，只供参考。

选片标准见 [docs/selection-criteria.md](docs/selection-criteria.md)，这样设计的原因见 [docs/decisions.md](docs/decisions.md)。

## 怎么用

- 点“看和记”：在页面里播放，旁边写小记。也可以点“在 YouTube 打开”。
- 小记和“已看”只保存在当前浏览器里，不会上传，也不在这个仓库里。
- 换设备前，在“我的小记”里导出备份，到另一边导入。也可以导出成 Markdown 放进自己的笔记。
- 直接双击 `index.html` 也能用，只是本地文件不能在页面里播放，会改成跳到 YouTube。不开 JavaScript 时，全部视频信息和参考要点仍然能读。

## 结构

| 文件 | 作用 |
|---|---|
| `videos.json` | 全部内容：分区、分组（`kind` 是 `main`、`branch` 或 `relax`）、每个视频的标题、频道、时长、日期、推荐理由、问题、参考要点，以及要点的核对方式 `checked` 和来源 `src` |
| `template.html` | 页面样式和交互 |
| `build.py` | 把 `videos.json` 填进 `template.html`，生成 `index.html` |
| `index.html` | 生成的页面 |
| `docs/` | 选片标准和决定记录 |

## 更新

1. 在 `videos.json` 里加、删、改视频。新视频先在 YouTube 上确认能播放，再填时长和日期。分组的 `ordered` 为 `true` 时按顺序编号。
2. 运行 `python3 build.py`（只用 Python 标准库）。

## 选片说明

由 Opus 和 Fable 挑选，Codex 和 Kimi 审过一轮。没有逐个看过视频。主线和数学补给的问题、参考要点对照过作者公开的讲义原文；其余标“未核对”的按通用知识写成。每个链接都在 `videos.json` 的 `updated` 日期核对过能播放。
